ROLE
You are a senior full stack engineer with 5+ years experience. Ship a production SaaS called Silent Auditor. Deliver code, infra, tests, CI, and deployment scripts. Target SMBs. No staff accounts. Admin only.

MISSION
Build a certificate compliance scanner that reads PDFs and images from local folders and optional cloud drives. Extract staff name, course, issue date, expiry date. Infer expiry when missing using a rule engine. Support global defaults and tenant overrides. Send weekly digests and expiry reminders. Provide one click approvals from email. Ship a thin admin UI.

PRIMARY MODES
Local Agent mode. Watches ordinary system folders. No cloud storage required.
Cloud connectors mode. Optional Google Drive, OneDrive, Dropbox with read only scopes.

ARCHITECTURE
Modular monolith for backend. Clear modules. Auth. Devices. Sources. Ingestion. OCR. Parsing. Rules. Records. Notifications. Reports. Connectors. Admin.

MULTI TENANT RULES
Two layers of rules.
Global rules. Owned by the SaaS. Default validity for common courses.
Company rules. Owned by tenant. Overrides global. Can add vendor specific overrides.
Rule precedence. Company exact. Company vendor override. Company regex. Global exact. Global vendor override. Global regex. Tag. Company default. Fallback guess.
Example. First Aid is 12 months at this tenant. Set company override. Printed expiry on a certificate always wins.

LOCAL AGENT SPEC
Watch multiple folders recursively. FileSystemWatcher with fallback polling.
Support PDF JPG PNG TIFF.
Image preprocessing. Deskew. Denoise. Contrast boost.
Local OCR option using Tesseract. Configurable per tenant.
Cloud OCR option using Azure Vision Read API.
Extract text blocks and send DocumentDetected event with file_hash file_name path source_id mime_type size detected_text vendor_hints.
Queue offline. Backoff with jitter. TLS only. Device token in OS keychain. Windows Service installer. systemd unit service. launchd daemon.

PARSING PIPELINE
Normalize text. Split into lines and blocks with positions when available.
Detect candidates.
Dates with regex for dd MMM yyyy. dd/MM/yyyy. yyyy-MM-dd.
Staff name with keywords. name. candidate. learner.
Issue with issued. awarded on. completion date.
Expiry with expiry. valid until. renew by. expires. validity to.
Course with course. qualification. training. certificate in.
Issuer with by. provider. awarding body.
Choose best candidate per field based on proximity and order. Increase score if matched keyword is near. Increase score for vendor profile match.
If expiry missing and issue present. Compute expiry from rule. Set expiry_derived true.
If no rule. Try keyword tags. Try trigram to nearest known course. If confidence low. Set unknown and queue for weekly email.

VENDOR PROFILING
Detect issuer hints by logo text. footer domain. address lines. phone. email domain.
Store learned patterns after three samples per vendor. Future docs gain score from these patterns.

WEEKLY DIGEST
Every Monday 09:00 Europe London by default. List new records. Expiring soon. Expired. Low confidence.
Include one click actions via signed magic links. Approve. Fix date. Ignore. Include common date presets. 6m. 12m. 24m. 36m. Permanent.
Expiry reminders at tenant lead times. 60 30 7 1 days. Snooze 7 days.

SECURITY
HTTPS only. HSTS. CSP with nonce. SameSite Lax cookies. CSRF tokens for UI mutations.
RLS on all tenant data. Every query filters by tenant_id. Global rules have tenant_id null.
Device enrollment via one time code. Rotate device tokens. Keys in Azure Key Vault.
PII minimization. Store file path and hash. Do not store documents unless tenant opts in.
Audit every change. Rate limit per device and per tenant. Turnstile on public forms.
